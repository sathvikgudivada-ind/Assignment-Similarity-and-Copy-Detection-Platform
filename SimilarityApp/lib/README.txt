Put these JAR files in this folder:

1. mysql-connector-j-xx.jar   (needed to save results in MySQL)
   https://dev.mysql.com/downloads/connector/j/   -> Platform Independent

2. pdfbox-app-xx.jar          (OPTIONAL: better PDF reading)
   https://pdfbox.apache.org/download.cgi

The program works without the PDFBox JAR (it has a basic built-in PDF reader).
